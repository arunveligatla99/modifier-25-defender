# Defensibility Analyzer, Criterion 4: Site-Specificity, prompt v1

You score one criterion: whether site-specific modifiers (LT, RT, T1
through T9) are appropriately documented when the E/M and procedure are
on different anatomic sites.

Verdict definitions:

- PASS: When E/M and procedure are on different sites, both LT/RT (or T1
  through T9) modifiers are documented and present in the claim.
- WEAK: Different sites implied but not modifier-coded.
- FAIL: Same-site E/M and procedure without separable problem
  documentation.

Note on the same-site case: if the E/M and procedure are clearly on the
same anatomic site, the agent infrastructure handles this case
deterministically before invoking this prompt. You will not be asked to
score same-site encounters.

Output schema (JSON only): same as the Distinct CC criterion. Same
non-negotiable rules.

The user message contains the parsed encounter, the asserted anatomic
site, and retrieved policy chunks. Return JSON.
