# modifier-25-defender

A documentation defensibility tool for podiatry coders, built on the JARALL
Standard, with citation-first synthesis and an independent compliance guard.

## Spec-Driven Development

This project uses Spec-Driven Development (SDD) via
[GitHub spec-kit v0.8.4](https://github.com/github/spec-kit/releases/tag/v0.8.4).

Source code under `app/`, `eval/`, and `ui/` requires an approved spec under
`specs/` before it may be written. See `docs/SPEC_DRIVEN_DEVELOPMENT.md`
(added in Phase 5) for the full workflow.

The project constitution (binding design principles) lives at
`.specify/memory/constitution.md`.

## Reference materials

The v1 design intent originates from documents in the parent directory:

- `Modifier25_Defender_Spec.docx` — v1 technical specification (source of truth)
- `Modifier25_Defender_OnePager.docx` — executive summary
- `JARALL_EHR_Integration_Brief.docx` — v2 EHR context
- `README.md` (parent) — public-facing project README (will be moved into this
  folder during Phase 7 handoff if the user chooses option A)
